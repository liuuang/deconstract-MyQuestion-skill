Deconstruct Mode — an interactive problem-decomposition skill designed for DeepSeek Harness (DSH). Follows a fixed workflow: clarify, decompose, acquire & quality-check info, decide, negation check, act. Each step waits for user confirmation before advancing.

> Core philosophy: **Confirm the method before starting. If the method is right, it may be solved immediately; if it's wrong, the longer you research, the worse it gets.**

# 2. Logic

## 1. Entry Point

| --- | --- | --- |

| chaotic | Stop first, not entering workflow | Not entered (re-enter after domain shifts via clarification) |

## 2. Base Loop (OODA × PDCA × Kolb unified)

Three models, one rotating circle. Each of the four steps carries one model's core purpose — Kolb perceives, PDCA understands, OODA acts; deciding the goal is the shared endpoint. Closed loop — feedback is the next round's perception, no separate step:

- **① Perceive info** (Kolb's core purpose / Observe / Check / Concrete Experience): take in reality. The output of action is new experience — feedback IS perception, the loop closes straight back here.
- **② Understand info** (PDCA's core purpose = Act-adjust / Orient / first half of Plan / Reflection → Conceptualization): make sense of reality.
- **③ Decide the goal** (shared: Decide + second half of Plan / concept chosen): pick a plan.
- **④ Act on it** (OODA's core purpose / Act / Do / Active Experimentation): execute → produce new experience → back to ①.

## 4. Quality-Check Tool Library (quality-tools.json)

Domain-specific quality-check tools are not hardcoded in the skill body. They live in `quality-tools.json` in the same directory, as a tree of key-value pairs: **domain → source type (general / people / things) → tool list**. Categories aim for MECE (mutually exclusive, collectively exhaustive); fall back to CRAAP when no matching tool is found. Tools are auto-matched by the user's industry at runtime. ## 2. 基本循环（OODA × PDCA × Kolb 三循环合一）

三个模型，同一个旋转的圆，四步各有一个核心目的归属：Kolb 管感知、PDCA 管理解、OODA 管实施，决策目标是共享终点。四步闭环——反馈即感知，不另设环节：

- **① 感知信息**（Kolb 核心目的 / Observe / Check / Concrete Experience）：接触现实。行动的产出就是新经验——反馈即感知，直接回到本步。
- **② 理解信息**（PDCA 核心目的 = A 调整 / Orient / Plan 前半 / 反思 → 抽象）：理解现状，提炼概念。
- **③ 决策目标**（共享环节 = Decide + Plan 后半 / 概念选定）：定方案。
- **④ 实施行动**（OODA 核心目的 / Act / Do / Active Experimentation）：执行 → 产出新经验 → 回到①。
